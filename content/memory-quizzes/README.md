# 路线小测题库

此处是独立的教学记忆题库，不修改视频事件、字幕成稿或正式考试事件。五、六、七号线分别有11、9、10题，其中走向题5、3、4题，项目顺序题各6题。对应加载边界为 `src/features/memory/quiz/bank.ts`。

## 来源与范围

- 路线方向、项目名称和顺序引用 `public/data/route-*.events.json` 中已发布的教学项目，追溯至 `content/event-calibrations/route-*.json`。不自动从所有事件生成题目。
- `videoSha256`、`subtitleSha256` 绑定原素材；`eventSignature` 保存事件 ID、名称、类型、方向和动作区间的快照。变化后题库关闭，须重新审阅，不能只修改签名恢复出题。
- `direction` 仅询问路线走向，不判断现场是否允许立即通行。`correct` 必须与引用项目的走向一致；掉头单独表示，不误记为普通左转。
- `sequence` 明确询问“下一个学习项目”，固定正确项目及两个不同的备选项目；项目均需已发布、名称可区分。六号线没有跨越未开放的转弯/连接节点出题，不把独立场景里的连接项目补进视频记忆。

所选画面均未完成目标转向，单独记录 `frame.atMs`、观察依据和核对日期。部分出口题比原动作区间起点早2秒；其余取已抽样校准的区间起点。没有通过指纹、字幕时间猜测或修改原暂停点来声明已核对。

题目定格视频、静音、不显示播放控件或教学字幕，固定遮住80%–94%的原片字幕区域；不受用户练习遮罩位置影响。此范围对选定画面核对使用，不推广到任意视频位置。原片道路和可见交通保留，不做碰撞、距离或转向操作判分。

七号线第二次掉头候选的上方大字直接写明掉头方向，未选为走向题。五号线车道调整边界存在疑点，六号线受阻转弯和七号线转弯后的临时选道补救均未用作唯一走向答案。

## 维护

新增或修改题目时，先回看原画面，确认定格位置在目标转向前、遮罩后不显示答案、备选项有唯一正确答案。引用和核对记录与修改一起提交；证据拼图、视频副本及浏览器截图不提交、不上传外部服务。

内容、题目、提示或素材变化会改变题库签名，旧小测记录不再用于当前比较。小测与回忆自评分别存储；通过某轮选择题不等于完整路线回忆或实际驾驶能力已被验证。
