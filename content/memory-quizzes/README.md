## 出题依据

- **认实景**要求认出定格画面的位置。优先用同一路线容易混淆的公交站、工业区路口等作备选，揭晓时指出围墙、候车亭、路牌或管廊等可回看特征。
- **记走向**要求回忆拍摄车接下来是左转、直行、右转还是掉头。直行题需核对拍摄车过路口前后走向，转向题需核对拍摄车完成动作后的道路。
- **接顺序**问紧接的上一项或下一项学习项目。**补缺项**给出连续三项的首尾，要求补上中间一项。备选取同线已发布项目，优先相近地点或相同类别；揭晓时按行驶顺序串起实景。
- 六号线受阻的「右转返回大学路」既不作为选项，也不出跨越受阻处的顺序或补缺题。五号线有疑点的车道调整边界、六号线可选的变道方向和七号线右转后的临时选道只在学习素材中按原说明使用。

路线记忆研究区分地点识别、地点与转向的关联、地点间顺序三种能力。本题库分别覆盖三者，并用补缺题检查能否同时接起前后两段。题目先呈现题干和必要的实景，再由学员主动查看选项，整轮后统一给出正确答案和回看。这些是设计依据，具体训练成效还需要学员试用验证。 [路线顺序研究](https://onlinelibrary.wiley.com/doi/10.1002/hipo.23574) [相似地标与路线识别实验](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2015.01936/full) [选择题反馈实验](https://pubmed.ncbi.nlm.nih.gov/18194050/)

## 画面核对

- 每道实景题保存 `frame.atMs`、遮罩范围、观察依据和核对日期。扩充时使用 FFmpeg 从本机正式发布版视频逐处抽取候选帧，走向题另取动作结束帧核对。详细时间和观察依据见各线 JSON。
- 题面定格视频、静音，隐藏播放控件和教学字幕，固定遮住纵向 80%–94% 的原片字幕区域。此范围按选定画面复核，与学习设置里的遮罩范围独立。
- 七号线第二次掉头使用 06:44 的接近画面，此时还未出现后续的掉头方向大字。432–434 秒的后续帧用于交叉核对，题面不播放这些帧。
- 原片道路标志和可见交通保留。认位置时以稳定特征区分，走向题以拍摄车辆的行驶路线为证据，现场通行条件仍须独立判断。

## 维护

- 题库使用 `version: 2`，入口为 `src/features/memory/quiz/bank.ts`。方向、名称及相邻项目引用 `public/data/route-*.events.json`，可追溯至 `content/event-calibrations/route-*.json`。
- `videoSha256`、`subtitleSha256` 绑定素材，`eventSignature` 保存各项目 ID、名称、类型、方向和动作区间。来源变化后须重新审阅画面和选项，再更新签名。
- 增题前检查题面有唯一正确答案，遮罩后教学标注不会直接泄露答案，走向帧在转向前，多项目题严格相邻。证据拼图、视频副本和浏览器截图保留本机。
- 题目、解释或素材变化会更新题库签名，新的本机小测成绩以当前题库为准，旧题库成绩不参与比较。
