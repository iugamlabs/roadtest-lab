# 学习界面与训练工作台

面向约 60 岁的 C2 学员，电脑优先。保持中性扁平样式、20px 基础字号和至少 56px 的主要操作按钮；使用已有 shadcn 组件，不添加展示型品牌页头或装饰阴影。

## 页面与导航

- `/`：简洁学习入口，上方复用 `MapRouteCards` 展示五、六、七号线教学轨迹示意及重点标签，每张卡片提供「开始记路线」，进入对应 `/memory/$routeId`。下方提供视频操作练习、灯光口令考核、学习资料入口，灯光卡片使用现有琥珀主题色描边。
- `/memory`、`/memory/$routeId`：主用实景路线记忆，支持跟着学、自己回忆、逐级提示、自评、薄弱路段重练和本机记录。准备区可进入路线小测，学习结束可测当前路段；小测锁定首次作答，整轮结束后核对并回看错题。走向题静音定格且隐藏字幕，窄屏保持方向文字完整，提交后焦点交给下一题。桌面视频与回忆区并排，窄屏到点后滚到问题。详见[路线记忆](route-memory.md)。旧 `/exam` 和 `/exam/$routeId` 重定向到此处，灯光考核 `/exam/lighting` 继续独立提供。
- `/train`：五、六、七号线选择；每条路线进入独立工作台。
- `/train/$routeId`：视频、关键操作、字幕、设置、项目列表和人工校准。
- `/materials`：优先展示路线图，右侧查阅、搜索同一条路线的成稿字幕；窄屏先图后文。放大窗口支持缩放、查看全图和键盘滚动。
- `/settings`：兼容旧书签，重定向至 `/train`；导航不再单列学习设置。

沿用官方 `sidebar-07` 的图标折叠形式；默认收起，在左上角保留 56px 展开按钮。选中链接具有 `aria-current`。手机导航使用 Sheet，选中后关闭。

## 训练布局

1024px 起采用两列：左侧视频与播放控制（教学字幕显示在视频底部浮层，可独立开关）；右侧使用已有 shadcn Tabs 切换「关键操作」与「路线图」，默认关键操作。关键操作保留当前项目、操作步骤、反馈和车辆操作台，地图复用 RouteMapViewer 的缩放、全图与键盘滚动；顶部不再重复提供地图弹窗入口。缩短说明文字、间距和重复容器，让常用操作优先位于首屏，避免用缩小字号和按钮来挤空间。

视频列在桌面滚动时保持可见，视频高度受视口限制。完整步骤、教学说明及结束练习入口放在视频侧，默认收起详细说明。操作台始终显示当前步骤，当前操作按钮有边框提示；灯光、观察、刹车完成后显示选中状态和勾选图标，文字反馈紧邻操作按钮。倒计时订阅原有独立操作时钟，视频倍速不影响等待。

窄屏上下布局；进入练习节点或从列表选择单项时将操作区滚入视口，避免用户寻找页面底部。操作区提供额外的暂停/继续按钮，避免暂停后需要滚回播放器。浏览器与用户字号、缩放设置可能使页面产生纵向滚动，不固定高度裁切操作内容。

## 设置、列表与媒体行为

播放速度及原声在播放器控制栏直接调整，立即生效并通过现有设置边界保存。会话音量与教学字幕显隐仅在当前路线页面保留。播放器支持前后 10 秒、带缓冲指示的进度条及全屏；所有跳转仍调用原控制器，不记为完成，跳转后手动播放。全屏包含教学字幕与控制栏，倍速 Select 的 Portal 挂在播放器容器内；原生全屏不可用时回退到铺满窗口，Esc 退出。练习进入操作／回顾阶段时退出全屏，不改变操作计时规则。播放器获得焦点后支持空格／K 播放暂停、左右键前后 10 秒、F 全屏、M 原声、C 字幕；按钮、滑块及 Select 保留各自键盘行为。遮罩与原声详细设置放在训练页 Sheet，使用统一 SettingsProvider；不再维护与持久化设置脱节的播放器副本。遮罩范围通过 React Hook Form 和 Zod 校验，提交后应用，错误关联输入。

打开手机导航、学习设置或练习项目调用控制器手动暂停，冻结操作计时；关闭不自动播放，也不自动恢复操作计时。从列表选择单项调用原有 retry，开始新尝试并关闭面板，将焦点交给操作区；仅关闭列表则回到原入口。路线图 Tab 沿用独立 map 暂停原因，查看期间冻结，切回关键操作后手动继续。选择项目时切回关键操作，再交还焦点；人工校准时使用独立面板。

这些界面调整不改变教学步骤、默认打灯等待、来源指纹、事件时间和人工校准逻辑，也不增加正式评分。人工校准仍会结束当前练习，保存后重新建立引擎会话。

## 验证

应用检查使用 `pnpm test`、`pnpm build`。浏览器验证需检查主页与路线入口、侧栏展开/折叠、路线图切换/缩放、设置保存与输入错误、Select 键盘操作、Dialog 关闭后的焦点、步骤反馈与暂停恢复，以及桌面、平板、手机的横向溢出和核心按钮位置。浏览器工作文件及截图保留在本机临时目录，不提交视频、浏览器包或生成产物。

本轮已使用本机 Chromium + Playwright 检查 1440×900、1366×768、1280×720、1024×768、768×1024、390×844 和 320×740 布局；桌面转弯与停车核心操作无需滚到页面底部，窄屏进入操作区后可就地暂停/继续。主页、资料与训练页无横向溢出，交互检查未发现页面运行异常。已检查设置持久化与错误提示、步骤纠正、打灯/观察/制动状态、单项完成/回看、项目选择焦点、Select 键盘操作、路线图缩放及关闭焦点、手机抽屉导航。

首页入口修正后使用本机 Chromium + Playwright 检查 1366×768、390×844、320×740 无横向溢出，并逐一检查三张路线卡通过键盘进入对应视频页、下方场景考试进入 `/exam`，及考试选择页保留三组考试／练习入口。构建和 TypeScript 检查通过。

训练页 Tabs 调整后检查三条路线的默认选项、键盘方向键切换、路线图缩放和全图，以及播放／全程练习中切到地图后暂停、切回后保持暂停。1366×768、1024×768、390×844、320×740 无横向溢出，Tab 点击区至少 56px；本机 Chromium 检查未发现运行异常。`pnpm build` 和媒体控制器 13 项测试通过。

播放器调整后使用本机 Chromium 检查字幕开关、会话音量及原声、进度拖动、前后跳转、键盘播放/暂停、原生全屏、全屏内倍速 Select，以及正常播放到练习节点时退出全屏。1366×768、1024×768、390×844、320×740 无横向溢出，并查看桌面、手机与全屏截图。`pnpm build` 与训练引擎/媒体控制器 33 项测试通过。
