# 路线场景考试

入口为 `/exam`，五、六、七号线工作台为 `/exam/5`、`/exam/6`、`/exam/7`。这是独立场景的教学考试：按路线项目顺序自动行驶，以透视道路、来车、行人和信号灯呈现场景。学员操作关键动作，不持续控制方向盘或油门。

## 内容与评分边界

- 视频学习及62项暂停练习继续独立运行，原始素材、来源指纹、字幕修订与人工暂停点不变。
- `src/features/exam/routes.ts` 是独立编排的场景蓝图。五号线22项，六号线20项，七号线22项；保留已发布视频练习项目的顺序、方向和自主识别类别，来源 ID 只用于追溯路线结构。
- 六号线额外编排“饭店后提前选择右侧车道”“右转返回大学路”两个场景连接项目，`referenceId: null`，不补造原片口令时间，不解禁原视频受阻节点。
- 场景几何、行驶距离、速度、灯光等待、观察有效期与评分均是教学模型。不是原考场的精确数字复刻，不模拟真实车辆动力学、实际视线、车身压线或停车距离。
- 视频校准的 `examEvents` 继续为空；场景蓝图不读取原片时间，不把 `visual-reviewed`、`asr-only`、人工暂停点或原教学步骤提升为正式考规。
- 当前规则版本为 `scenario-teaching-v1`。改变蓝图或随机算法时需要同时评估历史回放兼容性，必要时提升版本。正式考规需独立来源核实和发布，不能改名后沿用教学规则。
- 灯光、上车准备、熄火与开关车门尚未加入，不能宣传为覆盖完整官方考试。

## 随机与交通

同一路线、规则版本和32位无符号场景编号生成相同交通。随机算法不使用在线AI或服务端；换一组编号即可改变交通。

- 变道和超车安排相应方向的后车，超车返回阶段可以再次有右后方来车。
- 路口安排红灯、横穿行人或横向来车；公交站和检查区可安排行人。直线项目不生成无关冲突。
- 单个阶段不叠加互相矛盾的交通冲突，冲突在有限场景时间后解除。
- 车辆停车只冻结自身位移，其他交通及转向灯等待继续。手动暂停则冻结整个世界。
- 观察打开4.5秒实时窗口；执行时重新检查当前交通，观察点击不代表安全。
- 完成变道后更新实际车道；超车先驶出再返回原车道；转弯和掉头更新朝向及下一路段。动作过渡持续1.8秒；过渡中停车会停止动作进度，恢复行驶后继续。

道路长度96、正常速度8、慢行速度4是内部场景单位，不是官方考核距离或真实速度。24单位后可变道，60单位后可执行路口动作，80单位为冲突检查边界；到96单位时完成自动通过或结算漏项。界面使用路段名称，不显示这些内部数值。

## 教学评分

满分100。低于90立即结束；90可继续，走完路线后达到90为合格。每类违规扣10分，不使用尚未核实的当地扣分或不合格细则。

- 方向错误、过早执行、转向灯方向错误或不足3秒、执行前未观察或观察超过8秒、转弯停车前未减速、交通冲突中尝试通行、越过危险边界、越界变道、行驶状态不允许驻车/启动，以及漏项。
- 转向灯等待按独立有效时间计算；重复点击同一方向不重置，换方向重新计时。
- 观察左右顺序可以互换；停车瞭望要求到达路口前操作区停稳后再观察两侧。
- 已完成动作后保留车辆状态，6秒内需要关灯。超车左右两个阶段分别计时、观察与判断。
- 慢行/直线项目随位移通过，需要前方观察；慢行项目还需保持减速。主动识别项目没有额外语音口令。
- 驻车前必须停稳；靠边停稳后关灯、P挡、驻车制动完成收尾。
- 按场景、动作阶段及规则ID去重；同一次未纠正的违规不再叠加漏项扣分。独立的其他危险操作仍可单独扣分。
- 危险通行尝试扣分后保持原车道；驶到危险边界的车辆被停止在边界前。该保护行为不表示学员已正确制动。
- 允许安全等待，没有单纯等候超时扣分；安全的停车和慢行不是系统暂停。

## 时钟、暂停和播报

纯引擎接收单调时间，按实际相邻时间差更新。大于1.5秒的界面事件间隔自动暂停，不把界面卡顿算作学员错过路口。落后的时间戳不会倒退时钟。

| 情况 | 行为 |
| --- | --- |
| 正常行驶 | 自身位移、其他交通、有效用时及灯光计时继续 |
| 减速、停车 | 改变自身位移；其他交通及灯光计时继续 |
| 手动暂停 | 整个场景及操作计时冻结，禁用操作 |
| 页面隐藏 | 冻结并保留手动暂停；返回后手动继续 |
| 打开路线、说明、结束确认 | 暂停；关闭后不自行恢复 |
| 语音口令 | 播报期间冻结场景，完成后解除语音暂停；其他暂停原因保留 |
| 语音失败 | 保持暂停，不扣分；用户重试或明确选择文字回退 |
| 离开路由、刷新 | 进行中提示确认；中途进度不恢复 |
| 考试结束 | 停止世界计时，保存结果；原会话不能继续操作 |

TTS优先使用系统本地普通话声音，其次选择可用中文声音。声音加载等待2.5秒，单句播放等待上限30秒；实际完成回调驱动场景继续。取消、切换项目、卸载和重试后，旧语音回调不影响新会话。系统可用声音及是否联网取决于设备，提供试听和文字口令回退。

## 本机记录与回顾

- 设置键：`roadtest.scenario-settings.v1`；历史键：`roadtest.scenario-exams.v1`。
- 仅保存最近12次完整会话的结束结果（含主动中止），存入前、读取后经过Zod校验。进行中的考试不跨页面恢复。
- 记录规则版本、路线、随机编号、北京时间展示用的ISO结束时刻、分数、有效用时、已完成项目、最多2000条操作及扣分瞬间的车辆/位置/交通时间快照。
- 结果页支持查看扣分路况、相同场景重考、换一组考试和错项单独演练。错项演练单独建会话，不计入整条路线考试历史。
- 存储损坏或被禁用时仍可运行；保存失败明确提示，当前结果仍可查看。

## 验证

`pnpm test`覆盖三条路线顺序/方向、随机复现、完整路线多种种子无扣分通过、90分边界、危险时机、暂停/后台/卡顿、语音错误、迟到回调、本机数据损坏与存储失败。`pnpm build`同时检查原素材来源约束与TypeScript。浏览器验证与语音实际输出需在有中文声音的目标设备检查。
