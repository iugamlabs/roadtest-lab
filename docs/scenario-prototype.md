# 2D交互原型

入口 `/exam/prototype`，从考试首页“打开2D交互原型”进入。

本原型用于试用简化交互，仅有五号线两个可切换、可重来的独立片段：

- 大学路向左变道，参考 `5-lane-command` 的项目方向。
- 右转进入工业区，参考 `5-industrial-turn` 的路口连接。

两个片段不是连续全路线；局部SVG道路参考五号线路线图，保留大学路北行及向东进入工业区的连接。距离、行驶时间和交通为交互示意，不修改素材、事件核实状态、已有考试或本机成绩。

## 操作与节奏

固定六个按钮，采用语义颜色、不同图标、文字和选中状态共同区分。左右灯再次点击关闭；观察展开相关区域；减速降低行驶速度；停车停止自身车辆；通行根据当前位置恢复行驶或执行动作。转向轨迹自动完成。停车与暂停不同：停车时其他交通和打灯等待继续，暂停时全部冻结。

车辆正常缓慢靠近约12秒，减速后更慢；到达操作位置后一直等待，没有错过节点、观察失效或反应超时扣分。右转前需右灯、观察、减速；左变道需左灯和观察；灯光保持3秒可以与观察并行。这些是原型教学条件，不是已核实考规。未满足条件时文字解释，不扣分。

固定示意交通在有效时间18秒后解除：右转片段为横穿行人，变道片段为左侧来车。观察打开的区域持续显示交通变化，不设置隐藏失效倒计时。点击通行时重新判断交通，原型使用保护性拦截，不能描述为正式考试评分。动作过渡约3.2秒，期间仍可停车，再用通行继续。

页面隐藏、打开路线图或长于1.5秒的界面卡顿会暂停；返回后手动继续。开始和切换片段不自动朗读，可按口令旁的扬声器试听；失败时使用文字。此原型不保存设置和成绩。

## 代码与验证

`src/features/exam/prototype/model.ts` 为独立纯状态转换，`map.tsx` 为地图，`workspace.tsx` 为六键界面；复用已有shadcn组件、Lucide图标和TTS边界。主应用语义主题保持不变，操作色集中在 `src/styles.css` 的原型语义变量，支持深色主题。

验证目标包括：无时间压力、停车后交通继续、暂停冻结、观察和灯光并行、实际改变车道/方向、同一个通行按钮恢复行驶，以及桌面首屏和手机布局。下一步应先让使用者试用右转和变道，确认操作是否顺手，再决定完整路线和考试评分的扩展。
