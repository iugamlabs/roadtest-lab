# 科目三流程模拟与结果

`/exam/simulation` 提供五、六、七号线的 C2 流程模拟。每轮按顺序完成五个阶段。上车准备、C2 起步与停车收尾只需阅读或听取流程，再点一次确认。开场顺序参考用户提供的驾校《考试流程》图片，起步按 C2 自动挡使用 D 挡。

| 阶段 | 学员操作 |
| --- | --- |
| 上车准备 | 阅读或听取上车、身份核验、绕车检查、系安全带和启动发动机的顺序，确认进入灯光 |
| 模拟夜间灯光 | 先做「请打开前照灯」，再做从其余 11 条口令中随机抽出的 5 题。每题有起始灯光状态，提交后锁定。完成后按提示关闭车灯和仍开启的双闪，自动进入起步 |
| C2 起步 | 阅读或听取起步顺序，确认进入实景 |
| 实景路线 | 顺序观看 10 段静音短片，回答路线接续题或选择「想不起来，继续走」。提交后直接进入下一段，最后从终点短片进入停车收尾。六号线略过一处待核实转弯 |
| 停车收尾 | 阅读或听取靠边、停稳、驻车、熄火和下车顺序，确认完成本轮 |

## 结果与依据

结果以实景路线答对段数、第一次没接上的位置和逐段回看为主，另有灯光逐题回顾。灯光答错也可继续完成整轮。结果仅保留在当前页面会话。

灯光回顾按本地 [GA 1026—2022 规则库](../content/exam-rules/ga1026-2022-subject3.json) 已接入的灯光条款记录提交时的状态。临停示廓灯缺失且前照灯已关闭的组合仍列为未评判，双闪状态供回顾。流程模拟不出具整轮分数或合格结论。

语音默认开启，播报流程、灯光口令、实景题干和结果。在流程说明、路线过半及到达终点时给一句鼓励，题目照常作答。完成页按实际路线表现提供表扬或回看建议，并显示和播报「祝你科目三一次通过！」。灯光、实景与结果支持重听，所有阶段有文字可读。视频学习、路线小测、独立灯光考核和历史路线场景保持各自的结果。正式视频 `examEvents` 继续为空。
