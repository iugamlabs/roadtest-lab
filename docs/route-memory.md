# 实景路线记忆

## 产品方向

主线从虚拟车辆操作考核转向“看实景认路、主动回忆、核对遗漏”。目标是帮助学员在脑中接起整条路线，不把鼠标操作熟练程度当作驾驶能力。适用于五、六、七号线，电脑优先，保留大字与至少56px的主要操作区。

- 首页和 `/memory` 的路线卡片可直接进入路线学习或对应的小测准备页（`/memory/$routeId?quiz=true`）。两个页面均提供独立的灯光口令考核入口。
- 默认“跟着学”、连练5处；可以选择起点、一直练到终点，或重练上次需要提示/重练的项目。
- “跟着学”沿真实视频播放，在关键位置停下，展示位置、教学动作与下一项目；学员手动继续。
- “自己回忆”先展示道路，不显示当前项目名称。学员口头或在心里回答“这里是哪里、接下来怎么走、需要准备什么”，再点击查看讲解。
- 两级提示先给出前一项目，再给当前项目名称；用过提示不能标为“自己想起来了”。
- 揭晓后自评“自己想起来了 / 提示后想起来了 / 这段再练一次”，并继续下一段。自评不代表客观掌握，不算考试分数、不做语音识别、不收集录音。
- 回顾区展示逐项自评，可重练需要提示的项目、重练任一处、接着练后面5处，或从头独立回忆同一段。提前结束的未完成项保持未完成，不假定已经学会。

## 路线小测

记忆页顶部提供“路线小测”，学习或回忆结束后可“考考刚才这一段”。这是有确定答案的记忆题，与原有自评分开。

- 三条路线共113题，五号37、六号36、七号40。认实景题有定格和短片两种，辨别公交站、路口等位置。记走向题回忆下一步怎么走，接顺序题问相邻的上一项或下一项，补缺题给出三项的首尾并问中间一项。画面和答案引用见 `content/memory-quizzes/README.md`。
- 整条路线每轮抽10题，其中4道短片认实景、2道定格认实景，其余4题覆盖记走向、接顺序和补缺项。每条线的6个认实景点位每轮各考一次，点位的呈现形式随抽题变化。同轮考查项目互不重复，优先覆盖前中后三段和最近两轮未抽过的题。方向按钮固定为左转、直行、右转、掉头的位置与图标，其余题目打乱选项顺序。
- 分段小测只考已完成学习或回忆的项目。顺序题的前后两项、补缺题的全部三项都要在范围内，按题池调整认实景占比和实际题数，上限10题。
- 每题先呈现题干和必要的画面。学员先回忆，再按「查看选项」，选好后「确定答案」。确认时锁定首次提交并自动切题，末题提交后统一揭晓。保留「想不起来」，不限时。提前结束时未提交的选择按未作答统计。
- 默认用浏览器语音播报题号和题干，可关闭或重听。切题、结束、离开和页面隐藏时取消上一段播报，播放失败时可继续看文字答题。
- 定格画面准备好后才可查看选项。进入短片题后，从整线视频定位到已核对的起点并自动静音播放，到点停住，首次播完可查看选项或点「重看短片」。浏览器拦截自动播放时可点「播放短片」。题面固定遮罩覆盖底部原片字幕。切到后台、打开退出确认或离开本题时停止播放，返回后手动继续。加载失败可重试或结束本轮。
- 切题后焦点移到新题题干，并滚动到题目区域。查看选项时焦点进入选项组。保留键盘选择、清晰选中状态、至少56px主要点击区与退出确认。
- 结果总览分别显示答对、答错、想不起来和未作答，并列出各题型的答对数。逐题回顾将错题与未答放在前面，显示所选答案、正确答案及路标特征或项目衔接。可换一组、重测薄弱题、在弹窗中回看单题或待复习项目的实景片段。补缺项回看按顺序列出三段。关闭弹窗后回到原结果和触发按钮。
- 最近12次结束且至少提交1题的小测记录存于 `roadtest.route-quiz.v1.<routeId>`，Zod校验路线、题库签名、问题与选项、答案顺序、完成状态。同一题库的5题旧记录仍可打开。内容签名包含素材、项目快照、题目、解释和画面审阅数据，变化后当前题库历史重新累计。存储失败仍显示本轮结果，小测结果独立于回忆自评和旧考试记录。

“本机最近小测”可重新打开每轮逐题详情，包括实景回看。旧记录中使用提示后答对的题目仍有单独标记。正式考规、实际驾驶动作和现场交通判断仍不在评分范围。

## 视频与提示边界

复用 `TrainingVideoPlayer`，保留进度、前后10秒、倍速、音量、字幕与全屏。组件新增可选的 `concealAnswers`；原视频操作练习不启用此限制。

- 只使用 `eventsQueryOptions` 已通过发布边界的62项：五号22、六号18、七号22。六号线受阻项目继续排除，不从独立场景补造视频节点。
- 回忆位置使用现有已抽样校准动作区间的 `windowStartMs`；不改写 `practicePauseMs`、来源时间、指纹或 `examEvents`，也不声称这些位置已经逐段核实为所有讲解之前。
- 进入回忆旅程与停点时强制静音、隐藏成稿字幕，并用不透明局部遮罩覆盖原片字幕。范围沿用本机学习设置（默认82% / 8%），可在设置中对照画面调整。遮罩仅覆盖指定区域，不保证抹去所有画面提示。
- 揭晓后解除回忆限制，原声仍尊重用户偏好，可回看当前项目的实景和原声；随后继续下一处时重新应用限制，不覆盖持久化音量/字幕偏好。
- 连续项目从上一停点接着走；单项或不相邻的重练最多带入12秒前文，且不越过前一项目起点。路线第一处从视频开头播放。12秒仅为回放长度，不是反应期限。
- 到点自动暂停并退出全屏；播放进度跨过停点也必须停在本处，拖动不记完成。讲解回看只播放至当前动作区间结束，不连续泄露后续视频。
- 后台、手机导航、学习设置、离开确认和手动暂停均停止视频；返回或关闭后手动继续。缓冲时没有独立计时、没有扣分或超时。
- 需要视频可播放才能开始；媒体错误可重新加载，不伪造已经回忆完成。播放失败保留手动重试提示。

项目名称、走向来自已发布事件；动作要点沿用已有教学训练约定，不要求唯一操作顺序，不升级考规核实状态。没有新增凭空推断的建筑地标或独立考试口令。现场交通仍需当场观察，记熟路线不代替实际驾驶判断。

## 本机记录

`src/features/memory/model.ts` 为纯会话状态转换；`use-memory-playback.ts` 处理媒体播放、定位与暂停；`progress.ts` 负责Zod校验和本机记录。

自评逐项保存于 `roadtest.route-memory.v1.<routeId>`，每项保留最新评级、是否使用提示、尝试次数和更新时间。跟着学不写入回忆自评。记录绑定路线、原片/字幕指纹及项目内容签名；来源、项目时间或教学内容变化时不自动套用旧记录。损坏、被禁用或已满的存储不阻止本次学习，明确显示未保存提示。

进行中的播放位置不跨页面恢复，已完成自评保留；刷新、离开时提示。旧 `roadtest.map-assessments.v1` / `roadtest.scenario-exams.v1` 不读取为记忆成绩，也不删除原数据。

## 路线考试退场

首页和侧栏移除“场景考试”，改为路线记忆；原 `/exam` 重定向到 `/memory`，原 `/exam/$routeId` 重定向到对应记忆路线。旧模式参数不进入新流程。

原2D/透视场景实现与测试作为历史代码保留，不作为当前主流程；原型和早期透视页面仍可通过原链接访问。历史设计分别见 [2D路线说明](map-training.md)、[早期场景说明](scenario-exam.md)。

视频操作练习 `/train` 和纯阅读资料保留；灯光口令考核 `/exam/lighting` 独立保留，侧栏和首页直接进入，不经过退场的路线考试选择页。
