# 字幕与路线事件

## 单一成稿

前端只显示 `public/data/route-*.subtitles.json` 中的教学字幕，优先使用 `correctedText`，未修改的条目使用 `rawText`。不提供 ASR/OCR 切换、原文对照或校对状态，避免学员混淆。当前成稿以 ASR 为主，OCR 只作辅助；五号线另补入三条 ASR 漏掉的清晰讲解。

`content/subtitles/route-*.srt` 是同一成稿的标准 SRT 导出，保留毫秒时间。ASR 分句不重新猜测边界；OCR 补段保留自己的显示时间。文字校对不代表实际考试指令或动作窗口已核实。

## 来源与人工修订

- `raw/asr/route-*.srt`：原始 ASR 素材，Git 忽略，不修改。需使用未经裁剪或变速的同一段原始视频转写。
- `content/subtitle-sources/route-*.asr.json`：可提交的 ASR 原文快照，包含源文件名、原文及毫秒时间。
- `public/data/route-*.ocr.json`：已有 OCR 原文快照，保留乱码和识别失败提示，不直接编辑。
- `content/subtitle-reviews/route-*.json`：人工维护的文字修订、OCR 补段、修改理由、跨路线来源引用及重点疑点。
- `docs/subtitle-review.md`：自动生成的修订报告、重点回看项和候选口令时间索引。

```sh
pnpm import:asr          # 读取 raw/asr，保留原文快照
pnpm import:ocr          # 仅原始 OCR 有变化时运行
pnpm prepare:subtitles   # 生成前端 JSON、成稿 SRT 和校对记录
pnpm test
pnpm build              # 构建前也会重新生成成稿
```

原文与校正文分别存储。修订包含 `expectedRawText`，来源变化时停止生成，不能默默把旧修改应用到另一句；所有来源引用必须存在，重复修订或与 ASR 重叠的 OCR 补段会报错。修改后重新执行生成命令，再启动/刷新前端；不要直接修改生成文件。

ASR/OCR 允许一对多、多对一，字幕显示与声音时间可能存在小偏差。当前仅做文字和时间上下文对照，没有把两源逐条等同，也没有自动套用 OCR 文本。无法辨认的 OCR 不补入学员字幕。报告中的无 ASR 时间覆盖条目只是诊断信息，可能是无声提示、乱码或漏识别，仍需回看视频。

## 复核状态

成稿的 `reviewScope` 为 `text-only`。`text-reviewed` 表示已进行文字层面的审阅，不等于听音或画面核实；`needs-review` 用于显式疑点，以及涉及操作、方向、数值或规则的内容。含操作信息的字幕保留作者原意，不自动将其变为规则。推断补字及两源冲突须记录理由，不标记为已核实。

校对元数据供维护者使用，不在学习界面逐条展示。学员看到的是一份连续字幕；维护者通过校对报告与来源快照继续复核。

## 考试事件

字幕与路线事件分开存储。`trainingEventSchema` 是早期预留契约；本次画面定位使用独立的 `routeCalibrationSchema` / `calibratedEventSchema`，包含 ASR 口令位置、动作画面区间、练习暂停点、误差、来源字幕、画面依据及阻塞原因。还需要明确步骤要求、训练限时与评分规则，才能构建正式训练引擎。

报告里的独立口令形式只是候选定位，ASR 未区分考试播报与教练复述。至少区分考试指令、教练预告、事后解释、实际动作和临时交通情景；字幕时间不能直接变成操作触发时间，旧 DEMO 的人工推测节点不迁移。

仅核实的事件可进入正式模拟。视频播放时间决定路线位置，操作计时独立管理；暂停、缓冲、拖动、变速、页面隐藏及重练的计时和重置行为应另行定义。灯光和上车准备作为独立模块，不虚构成当前影片中的片段。

三条路线的画面定位与剩余疑点见 [事件校准记录](event-calibration.md)。已生成 63 项定位（五号线 22、六号线 19、七号线 22），覆盖 47 条独立口令候选，另外补入公交站、选道等项目。已查看 38 张全程索引及各节点边界图；不是完整逐帧观看或独立听音。此阶段可以接入通过画面复核的暂停练习数据，尚不能接入正式评分。

## 可重复的校准流程

```sh
pnpm prepare:subtitles
pnpm prepare:events       # 校验来源、覆盖率、边界，生成练习事件和报告
pnpm calibrate:media      # 需本机 FFmpeg/FFprobe；校验原片后生成证据工作台
```

- `content/event-calibrations/media.json`：原片 SHA-256、尺寸、帧率和时长；更换、裁剪或变速后必须重新校准，不能只修改指纹继续沿用。
- `content/event-calibrations/route-*.json`：可提交的定位源，独立于字幕校对；字幕变动也会触发指纹不符，需重新审阅受影响来源。
- `public/data/route-*.events.json`：生成的暂停练习数据，只导出画面定位已审阅且没有阻塞项的事件；未满足条件的节点列入 `excludedEventIds`。`examEvents` 显式为空，不能把 `events` 当正式模拟白名单。
- `artifacts/calibration/index.html`：维护者本地证据工作台，默认仅显示集中疑点，可切换所有项目，查看原片时间、边界图、来源字幕和原声回放。
- `artifacts/calibration/route-*/frames/`：原片每秒一帧的带时间标注图；原视频为零起点、30fps，脚本核实参数后按源帧号选取。全程索引每 5 秒一帧，边界图在动作起止前后各 2 秒取样。
- 疑点 MP4 由原片截取并转为 H.264/AAC，便于直接回放。工作台、帧、片段全部忽略 Git，不修改 `raw/`，不上传外部服务。

画面复核只核实可见位置和示范动作。驾驶员脚部、后视镜注视、手刹等未被拍摄时，不能声称已直接观察其动作。`audioStatus: asr-only` 明确表示重用已有转写，尚未独立听音；`ruleStatus: unverified` 保留考规核实边界。当前的练习暂停点和 ±2–5 秒抽样误差仅适用于暂停教学，不用于连续考试扣分。

等待、提前/事后讲解、负面示范与条件补救保存为独立标注。不得把前方教练车的停车当作拍摄车辆的停车，也不得用提前讲解替代实际操作。七号线后段停车瞭望已按拍摄车辆约 11:15 后接近停止线重新定位，前车约 11:07 右转的过程单独记录。

本次尚未把事件接入学习页面，没有动作状态机或评分。下一步可从这些暂停练习数据开始实现状态机、媒体事件处理和单项重练；正式模拟再补独立听音与规则依据。
