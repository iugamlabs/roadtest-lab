# 路考练习室

汕头大学路科目三路线学习与场景考试工具。第一阶段面向约 60 岁的学员，电脑优先，兼顾手机和平板，仅支持 C2 自动挡。

当前支持三条实景路线、视频播放与回看、局部字幕模糊、学习设置、统一教学字幕，以及 62 项暂停操作练习。可开始全程练习或选择单项，视频到节点暂停后按步骤操作；支持车辆状态判断、独立计时、纠正提示和重练。字幕以 ASR 为主、OCR 辅助校对；前端只显示一份成稿，原文、修订理由和待核实项保留在仓库。练习使用独立校准的时间点，不沿用旧 DEMO 的节点、方向或评分。

从首页或导航“场景考试”进入 `/exam`，使用已确认的[2D路线模式](docs/map-training.md)。五、六、七号线分别提供22、20、22项连续项目，车辆沿路线图重绘的道路自动行驶。固定六个按钮：左灯、右灯、观察、减速、停车、通行；路线卡片分别进入考试或舒缓练习，练习到点等待、不计分、不设反应时限。操作考核采用教学评分100分、低于90立即结束；提供随机交通、TTS及文字回退、单项重练、错项2D路况回顾和本机最近12次考核记录。不将视频校准数据当成正式评分依据，不增加业务后端。

最初两个片段的2D原型继续保留在 `/exam/prototype`，详见[原型说明](docs/scenario-prototype.md)。早期透视场景移至 `/exam/legacy/$routeId`，原有历史在首页折叠区查看，记录和规则与新2D模式分别保存，详见[旧版说明](docs/scenario-exam.md)。

进入视频路线后先观看视频，点击“开始全程练习”从当前位置练习；需要从头开始时先拖至开头。操作完成后手动继续，也可重练本项或回看暂停点前 5 秒。页面隐藏、路线图和用户暂停会冻结操作计时，回来后手动继续；拖动中止当前尝试，不将跳过记为完成。详细行为与教学步骤见 [训练引擎约定](docs/training-engine.md)。视频暂停练习不计分、不设超时淘汰，与独立场景考试分开；不提供直接按原片计分的正式模拟。

主页以五、六、七号线路线卡片展示教学轨迹示意与重点标签，每张卡片通过「进入视频练习」直达对应 `/train/$routeId`；下方保留场景考试（`/exam`）、灯光考试、学习资料三个入口，不重复长段介绍。侧栏“路线练习”仍进入 `/train` 选择实景路线。`/materials` 学习资料使用 shadcn Tabs 切换路线图与字幕、考试流程、模拟灯光考试（12 条口令操作对照及图片中的考试说明）。默认显示路线资料，切换器位于页面标题栏右侧，窄屏在标题下方展示。新增内容转录自用户提供的《考试流程》图片，尚未独立核实现行考规；保留原图起步提示并标明“挂一挡”不直接适用于 C2，学习资料保持纯阅读，灯光 Tab 仅展示口令操作对照和图片说明。首页和考试选择页 `/exam` 均提供灯光考试入口，进入独立页面 `/exam/lighting` 进行简单口令考核：随机抽取 5 条不重复口令，每题 20 分、不限时，选择操作后显示反馈，手动进入下一题，结束查看成绩和逐题回顾；支持语音开关、重听和文字回退。五种灯光操作使用固定位置、不同图标及颜色区分，答题后以实色背景和“已选”标记确认选择；开始、重听、继续、结束等按钮也配有用途图标和颜色，支持明暗主题。考试页面不展示答案对照，离开页面后重置，不保存考试历史；这是独立的教学自测，不使用图片中的时限和扣分规则，也不接入路线评分。桌面导航默认折叠，顶部按钮可展开。训练页将视频和操作台并排展示，当前步骤、操作反馈、打灯倒计时及车辆操作状态同步更新；“练习项目”可打开侧面板选择单项，完整步骤在视频下方展开。

播放器将教学字幕显示在画面底部，可独立开关；支持全屏、前后 10 秒、进度与缓冲、原声开关和音量。全屏保留字幕与控件，到练习操作节点自动退出全屏。提供 0.75、1、1.25、1.5、1.75、2 倍速，原声和速度调整立即生效并保存，音量及字幕显隐仅在当前路线会话保留。训练页“学习设置”侧面板管理原声、字幕遮罩与范围，无需离开路线；旧 `/settings` 链接会转到路线选择。打开设置或项目列表时暂停，关闭后手动继续；选择单项则开始该项新尝试。视频加速不影响操作计时或打灯等待。

节点不匹配时，可点击路线页的“人工校准”：选择项目，对照视频播放、拖动或按 0.1/1 秒微调，点击“使用当前画面时间”后“保存本项”；也可输入 `03:48.500` 或秒数。人工时间按路线保存在本机，正常触发、单项重练和回看都会使用新时间。可恢复单项/整条路线默认时间，或在“备份与恢复”中导出、导入。校准会结束当前练习，完成后重新开始；原始素材、默认校准及其来源记录保持不变。

路线定位、范围限制和剩余疑点见 [事件校准记录](docs/event-calibration.md)。维护者可运行 `pnpm prepare:events` 生成事件数据和报告；安装 FFmpeg 后运行 `pnpm calibrate:media`，打开 `artifacts/calibration/index.html`，集中查看疑点原声片段、逐项证据图和字幕依据。所有音视频处理在本机进行，原片保持不变。画面复核不等于独立听音或考规核实，正式评分事件尚未开放。

## 启动

需要 Node.js 22.12+、pnpm 12.4.2（见 `packageManager`）。

```sh
pnpm install
pnpm prepare:media
pnpm dev
```

`prepare:media` 需要本机安装 FFmpeg（含 `ffprobe`），从 `raw/` 准备三段视频和三张路线图到 `public/media/`。视频统一使用 H.264 / yuv420p + AAC，避免 Linux Chrome 无法解码 H.265 时只有声音没有画面；已有兼容原片直接复制，其余转码并将 MP4 索引前置，保留尺寸、帧率和时间轴，校验各轨起点、时长及视频帧数。原始素材和校准来源指纹不会被修改。首次转码需等待，后续通过原片、发布文件 SHA-256 与转码版本复用结果，记录位于被 Git 忽略的 `public/media/*.prepare.json`。素材缺失时会报告对应文件。媒体文件与 `raw/` 均不提交 Git；另一台设备可以准备素材或同步已准备的视频。Vite 构建会将已准备的媒体复制到 `dist/media/`，部署应从这里同步，不直接修改部署文件。

```sh
pnpm import:ocr  # 原始 SRT 有变化时，重新生成可追溯的 OCR JSON
pnpm import:asr  # ASR 素材有变化时，更新原文快照
pnpm prepare:subtitles # 应用人工修订，生成唯一成稿、SRT 与校对记录
pnpm test        # 字幕、数据边界、训练状态机与媒体控制检查
pnpm build       # 生成路由、生产构建、TypeScript 检查
pnpm typecheck   # 首次请先运行 dev 或 build，生成 routeTree.gen.ts
pnpm preview
```

## 结构

```text
src/routes/             TanStack Router 文件路由与页面
src/components/ui/      shadcn/ui 组件
src/features/content/   路线、字幕查询及 Zod 数据契约
src/features/settings/  学习设置与本机持久化
src/features/training/  训练引擎、媒体控制、操作面板与项目重练
src/features/exam/      路线场景、随机交通、教学评分、TTS与本机考试回顾
src/features/exam/map/  当前主用2D道路、连续轨迹、六键交互与独立考核记录
src/lib/                通用工具及按需加载的 Motion 特性
public/data/            前端使用的统一字幕 JSON，以及保留的 OCR 来源快照
content/subtitle-sources/ 可提交的 ASR 原文快照
content/subtitle-reviews/ 人工修订、来源引用与待核实项
content/subtitles/      同一成稿的标准 SRT 导出
public/media/           本机准备的视频和路线图，Git 忽略
scripts/                素材准备与字幕导入
docs/content-workflow.md 字幕与事件校对约定
```

React + TypeScript + Vite；Tailwind CSS；shadcn/ui；TanStack Router + Query；React Hook Form + Zod；Motion 使用 LazyMotion 异步加载，尊重减少动态效果设置。无后端、无账号、无远程转写服务。

## UI 与主题

应用布局基于官方 shadcn `sidebar-07` block，导航已适配 TanStack Router。桌面左侧栏默认折叠，顶部提供收起/展开按钮，手机使用 Sheet 抽屉；页面复用 Card、Badge、Alert、Input、Label、Select、Switch 等标准组件。路线页返回按钮位于标题左侧，播放速度使用 Select，视频路线页右侧使用 shadcn Tabs 切换关键操作与路线图，地图支持缩放、全图和键盘滚动；查看路线图时暂停视频和操作计时，切回关键操作后手动继续。学习资料的路线图仍可通过 Dialog 放大查看。布局与后续维护约定见 [UI 工作台](docs/ui-workspace.md)。

`src/styles.css` 的 `:root` / `.dark` 使用 shadcn 标准语义变量，包含 `sidebar-*` 和 `--radius`。后续可将 shadcn Themes 生成的变量替换到这两个作用域；页面配色、边框、圆角和焦点样式都会跟随主题。当前采用无卡片阴影的中性扁平样式，保留 20px 基础字号和至少 56px 的主要按钮。

## 当前边界

- 视频位置触发暂停练习；操作计时独立于视频暂停与播放倍速。按钮不影响影片中的真实车速，也不代表工具已经检测到实际驾驶动作，不计分。
- 2D场景采用路线图结构示意，车道尺寸、距离、交通及扣分为教学模型，不是精确考场复刻。默认舒缓练习，操作考核也到点等待，不测试连续驾驶反应或实际转向；尚未覆盖灯光和上车准备，不代表完整官方考试。中文TTS依赖系统可用声音，缺失时明确暂停并提供文字回退。
- 练习记录仅保留在当前路线会话，刷新、离开路线或重新开始全程练习会重置；学习设置仍在本机保存。
- 当前视频为教学片，有原声和画面字幕。字幕遮罩为 CSS 局部模糊，默认顶部位置为 82%、高度为 8%，可对照画面调整；默认关闭，设置暂时共用于三条路线。已有本机设置优先，可在学习设置中点击“恢复默认学习设置”应用项目默认值。
- 已完成文字层面的 ASR/OCR 交叉校对与独立的抽样画面定位，尚未独立逐段听音或核实考规。画面定位不升级字幕文字状态，也不授权考试评分；详见 [校对记录](docs/subtitle-review.md)、[事件校准](docs/event-calibration.md) 和 [内容维护流程](docs/content-workflow.md)。
- 本次仅搭建当前仓库内的项目，未配置线上托管。静态部署需要支持 SPA 路由回退至 index.html，并准备媒体文件；不需要业务后端。

考试路线卡片提供「进入考试」「进入练习」两个入口，详情页不再切换模式。语音与操作音效默认开启，支持开考、逐节点、扣分和结束播报、试听和重听；依赖设备中文TTS，失败时可改用文字。按钮和地图同步强化操作结果，通行采用真实车辆驶离录音。音效随项目本地提供，来源见 [音效记录](src/features/exam/audio/ASSETS.md)。
