# 路考练习室

汕头大学路科目三路线学习与场景考试工具。第一阶段面向约 60 岁的学员，电脑优先，兼顾手机和平板，仅支持 C2 自动挡。

当前支持三条实景路线、视频播放与回看、局部字幕模糊、学习设置、统一教学字幕，以及 62 项暂停操作练习。可开始全程练习或选择单项，视频到节点暂停后按步骤操作；支持车辆状态判断、独立计时、纠正提示和重练。字幕以 ASR 为主、OCR 辅助校对；前端只显示一份成稿，原文、修订理由和待核实项保留在仓库。练习使用独立校准的时间点，不沿用旧 DEMO 的节点、方向或评分。

新增独立的[路线场景考试](docs/scenario-exam.md)，从首页或导航“场景考试”进入 `/exam`。五、六、七号线分别编排22、20、22项示意场景，车辆自动行驶，随机产生来车、行人和红灯；学员的减速、停车、等待、变道和转弯会改变场景状态。满分100，低于90立即结束；采用独立教学评分，不将视频校准数据当成正式评分依据。支持系统中文TTS、文字回退、错项路况回顾、相同场景重考和本机最近12次记录；不增加业务后端。

进入视频路线后先观看视频，点击“开始全程练习”从当前位置练习；需要从头开始时先拖至开头。操作完成后手动继续，也可重练本项或回看暂停点前 5 秒。页面隐藏、路线图和用户暂停会冻结操作计时，回来后手动继续；拖动中止当前尝试，不将跳过记为完成。详细行为与教学步骤见 [训练引擎约定](docs/training-engine.md)。视频暂停练习不计分、不设超时淘汰，与独立场景考试分开；不提供直接按原片计分的正式模拟。

主页提供学习引导，点击“开始路线练习”进入 `/train` 选择路线；`/materials` 同时提供路线图与字幕搜索。桌面导航默认折叠，顶部按钮可展开。训练页将视频和操作台并排展示，当前步骤、操作反馈、打灯倒计时及车辆操作状态同步更新；“练习项目”可打开侧面板选择单项，完整步骤在视频下方展开。

播放器提供 0.75、1、1.25、1.5、1.75、2 倍速，原声和速度调整立即生效并保存。训练页“学习设置”侧面板管理原声、字幕遮罩与范围，无需离开路线；旧 `/settings` 链接会转到路线选择。打开设置或项目列表时暂停，关闭后手动继续；选择单项则开始该项新尝试。视频加速不影响操作计时或打灯等待。

节点不匹配时，可点击路线页的“人工校准”：选择项目，对照视频播放、拖动或按 0.1/1 秒微调，点击“使用当前画面时间”后“保存本项”；也可输入 `03:48.500` 或秒数。人工时间按路线保存在本机，正常触发、单项重练和回看都会使用新时间。可恢复单项/整条路线默认时间，或在“备份与恢复”中导出、导入。校准会结束当前练习，完成后重新开始；原始素材、默认校准及其来源记录保持不变。

路线定位、范围限制和剩余疑点见 [事件校准记录](docs/event-calibration.md)。维护者可运行 `pnpm prepare:events` 生成事件数据和报告；安装 FFmpeg 后运行 `pnpm calibrate:media`，打开 `artifacts/calibration/index.html`，集中查看疑点原声片段、逐项证据图和字幕依据。所有音视频处理在本机进行，原片保持不变。画面复核不等于独立听音或考规核实，正式评分事件尚未开放。

## 启动

需要 Node.js 22.12+、pnpm 12.4.2（见 `packageManager`）。

```sh
pnpm install
pnpm prepare:media
pnpm dev
```

`prepare:media` 从 `raw/` 复制三段视频和三张路线图到 `public/media/`，原始素材不会被修改。素材缺失时会报告对应文件。媒体文件与 `raw/` 均不提交 Git；另一台设备需要自行准备素材。Vite 构建会将已准备的媒体复制到 `dist/media/`。

```sh
pnpm import:ocr  # 原始 SRT 有变化时，重新生成可追溯的 OCR JSON
pnpm import:asr  # ASR 素材有变化时，更新原文快照
pnpm prepare:subtitles # 应用人工修订，生成唯一成稿、SRT 与校对记录
pnpm test        # 字幕、数据边界、训练状态机与媒体控制检查
pnpm build       # 生成路由、生产构建、TypeScript 检查
pnpm typecheck   # 首次请先运行 dev 或 build，生成 routeTree.gen.ts
pnpm preview
```

## 结构

```text
src/routes/             TanStack Router 文件路由与页面
src/components/ui/      shadcn/ui 组件
src/features/content/   路线、字幕查询及 Zod 数据契约
src/features/settings/  学习设置与本机持久化
src/features/training/  训练引擎、媒体控制、操作面板与项目重练
src/features/exam/      路线场景、随机交通、教学评分、TTS与本机考试回顾
src/lib/                通用工具及按需加载的 Motion 特性
public/data/            前端使用的统一字幕 JSON，以及保留的 OCR 来源快照
content/subtitle-sources/ 可提交的 ASR 原文快照
content/subtitle-reviews/ 人工修订、来源引用与待核实项
content/subtitles/      同一成稿的标准 SRT 导出
public/media/           本机准备的视频和路线图，Git 忽略
scripts/                素材准备与字幕导入
docs/content-workflow.md 字幕与事件校对约定
```

React + TypeScript + Vite；Tailwind CSS；shadcn/ui；TanStack Router + Query；React Hook Form + Zod；Motion 使用 LazyMotion 异步加载，尊重减少动态效果设置。无后端、无账号、无远程转写服务。

## UI 与主题

应用布局基于官方 shadcn `sidebar-07` block，导航已适配 TanStack Router。桌面左侧栏默认折叠，顶部提供收起/展开按钮，手机使用 Sheet 抽屉；页面复用 Card、Badge、Alert、Input、Label、Select、Switch 等标准组件。路线页返回按钮位于标题左侧，播放速度使用 Select，路线图使用支持缩放、滚动的 Dialog 弹窗；打开路线图时暂停视频，关闭后手动继续。布局与后续维护约定见 [UI 工作台](docs/ui-workspace.md)。

`src/styles.css` 的 `:root` / `.dark` 使用 shadcn 标准语义变量，包含 `sidebar-*` 和 `--radius`。后续可将 shadcn Themes 生成的变量替换到这两个作用域；页面配色、边框、圆角和焦点样式都会跟随主题。当前采用无卡片阴影的中性扁平样式，保留 20px 基础字号和至少 56px 的主要按钮。

## 当前边界

- 视频位置触发暂停练习；操作计时独立于视频暂停与播放倍速。按钮不影响影片中的真实车速，也不代表工具已经检测到实际驾驶动作，不计分。
- 独立场景考试按路线项目顺序改编，场景距离、交通及扣分为教学模型，支持操作影响场景；尚未覆盖灯光和上车准备，也不模拟驾驶物理或完整官方考试。中文TTS依赖系统可用声音，缺失时明确暂停并提供文字回退。
- 练习记录仅保留在当前路线会话，刷新、离开路线或重新开始全程练习会重置；学习设置仍在本机保存。
- 当前视频为教学片，有原声和画面字幕。字幕遮罩为 CSS 局部模糊，默认顶部位置为 82%、高度为 8%，可对照画面调整；默认关闭，设置暂时共用于三条路线。已有本机设置优先，可在学习设置中点击“恢复默认学习设置”应用项目默认值。
- 已完成文字层面的 ASR/OCR 交叉校对与独立的抽样画面定位，尚未独立逐段听音或核实考规。画面定位不升级字幕文字状态，也不授权考试评分；详见 [校对记录](docs/subtitle-review.md)、[事件校准](docs/event-calibration.md) 和 [内容维护流程](docs/content-workflow.md)。
- 本次仅搭建当前仓库内的项目，未配置线上托管。静态部署需要支持 SPA 路由回退至 index.html，并准备媒体文件；不需要业务后端。
